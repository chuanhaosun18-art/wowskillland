# 保研全流程复盘方法论

## 这个 Skill 解决什么

帮有保研资格学校的同学理清保研全流程，从大一准备到最终录取，覆盖政策、绩点、比赛、材料、面试、择校六大环节。

## 什么算做完

- 能完整说出从大一到大四的保研时间线，包括每个阶段该做什么、重点是什么
- 能列出本校/本院承认的比赛名单，并判断某个比赛是否值得参加
- 个人陈述和简历中每个亮点都有“埋点”设计，且能应对老师基于这些点的追问
- 面试PPT每一页内容都是自己真正做过、了解的，不存在夸大或编造的内容
- 择校有清晰的排序逻辑（城市→专业→学校），且每个选择都能从就业角度说明理由
- 整个流程规划对使用者有效，能从中获益（如拿到夏令营offer或最终录取）

## 关键岔路口

以下每条判断都来自一次真实执行，标注了它出自哪一步。

### 在哪一步你会停下来回头验证？

- 当**不确定某个比赛是否有含金量**时，查询学院官方承认名单，找学长学姐确认实际加分情况，不要凭感觉判断（适用：选择比赛时；来源：执行第 0 步）

### 什么情况下你会要求补充信息而不是直接动手？

- 当**用户没有明确目标院校或专业方向**时，先了解用户的专业背景、兴趣方向和就业意向，再给出择校建议（适用：用户在择校环节犹豫不决；来源：执行第 0 步）

### 哪一步必须查、必须跑，不能靠判断？

- 当**需要查询具体学校的保研政策或比赛名单**时，引导用户去学校官网、学院官网查询，或找学长学姐确认，不能凭空编造（适用：用户询问具体学校政策时；来源：执行第 0 步）

### 什么现象一出现，你就知道当前这条路走不通？

- 当**发现用户成绩排名明显不够或没有保研资格**时，如实告知用户保研可能走不通，建议考虑考研、出国或就业等其他路径（适用：用户是大三但绩点排名很靠后；来源：执行第 0 步）

## 边界与人工接管

**不适用于：**
- 只适用于有保研资格（推免名额）的学校；没有保研资格的同学应走考研、出国或就业等其他路径

**出现以下情况必须交回给人：**
- 当用户询问具体某所学校的保研加分细则（不同学校差异大，无法统一回答）时，应建议用户去该校官网查询或联系该校学长学姐；当用户涉及个人隐私信息（如具体绩点、排名）时，应提醒用户自行确认
