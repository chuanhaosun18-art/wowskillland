# 保研经验整理助手

## 功能概述
本 Skill 帮助本科生系统化整理保研经验，分为**材料准备**、**导师联系**、**复试技巧**三大模块，输出分阶段行动清单和可直接套用的模板。

## 使用流程

### 第一步：确认用户需求
先询问用户当前处于保研的哪个阶段，以及需要重点整理哪个模块。

### 第二步：按模块输出内容
根据用户需求，选择对应模块输出分阶段行动清单和模板。

---

## 模块一：材料准备

### 阶段 1：基础材料收集（建议大二下~大三上）

#### 行动清单
- [ ] 打印并扫描所有学期的成绩单（中英文各一份）
- [ ] 整理获奖证书扫描件（按级别排序：国家级 > 省级 > 校级）
- [ ] 整理科研经历证明（论文、专利、项目结题报告）
- [ ] 准备身份证、学生证复印件
- [ ] 建立电子档案文件夹（按类别分目录）

#### 模板：成绩单整理表
```
| 学期 | 课程名称 | 成绩 | 学分 | 绩点 | 备注 |
|------|----------|------|------|------|------|
| 大三上 | 高等数学 | 95 | 4.0 | 4.0 | 核心课 |
```

### 阶段 2：个人陈述撰写（大三上~大三下）

#### 行动清单
- [ ] 梳理个人经历亮点（学术、科研、实践、竞赛）
- [ ] 撰写初稿（800-1500字）
- [ ] 找老师/学长学姐修改润色
- [ ] 根据目标院校定制不同版本

#### 模板：个人陈述结构
```
1. 开篇（150字）：我是谁 + 申请目标 + 核心优势一句话
2. 学术背景（300字）：成绩排名、核心课程、学术兴趣
3. 科研经历（400字）：项目名称、我的角色、具体贡献、成果
4. 实践与竞赛（200字）：体现综合素质
5. 未来规划（200字）：研究生阶段目标 + 职业方向
6. 结尾（150字）：为什么选择该院校 + 表达诚意
```

### 阶段 3：推荐信准备（大三下）

#### 行动清单
- [ ] 确定推荐人（2-3位：专业课老师、科研导师、辅导员）
- [ ] 准备推荐信素材包（成绩单、简历、个人陈述）
- [ ] 提前2-3周与推荐人沟通
- [ ] 跟进推荐信提交进度

#### 模板：推荐信邀请话术
```
尊敬的X老师：
您好！我是XX专业20XX级的XXX，曾选修您的《XXX》课程，获得XX分。
目前我正在准备保研申请，想恳请您为我撰写一封推荐信。
我已将个人简历、成绩单和申请材料整理好，附件供您参考。
若您方便，我可以在您指定的时间当面沟通。
非常感谢您的支持！
学生：XXX
日期：XXXX年XX月XX日
```

## 模块二：导师联系

### 阶段 1：选择导师（大三下 3-5月）

#### 行动清单
- [ ] 确定研究方向（结合兴趣和就业前景）
- [ ] 搜集目标院校导师列表（学院官网、学术数据库）
- [ ] 筛选导师（看研究方向、近3年论文、项目经费、学生评价）
- [ ] 列出备选导师清单（按优先级排序，建议5-8位）

#### 模板：导师筛选评估表
```
| 导师姓名 | 研究方向 | 近3年论文数 | 项目经费 | 学生评价 | 匹配度(1-5) | 优先级 |
|----------|----------|------------|----------|----------|------------|--------|
| 张XX | 机器学习 | 8 | 充足 | 好 | 5 | 1 |
```

### 阶段 2：撰写第一封邮件（大三下 5-6月）

#### 行动清单
- [ ] 写邮件草稿（500字以内）
- [ ] 附上个人简历和成绩单
- [ ] 检查邮件格式和错别字
- [ ] 选择合适时间发送（工作日上午9-11点）

#### 模板：第一封联系邮件
```
标题：保研申请-XX大学XX学院-XXX（学校+专业+姓名）

尊敬的X老师：
您好！我叫XXX，是XX大学XX专业20XX级本科生，专业排名X/X，GPA X.XX。
我对您的研究方向「XXX」非常感兴趣，尤其是您在《XXX》论文中提出的XXX方法。
我在本科期间参与了XXX项目（简述经历），积累了一定的科研基础。
希望能有机会在研究生阶段加入您的课题组，向您学习。
随信附上我的简历和成绩单，恳请您在百忙之中查阅。
期待您的回复，谢谢！

此致
敬礼
XXX
日期：XXXX年XX月XX日
联系方式：手机/邮箱
```

## 模块三：复试技巧

### 阶段 1：自我介绍准备（复试前2周）

#### 行动清单
- [ ] 撰写中英文自我介绍各一份（1-2分钟）
- [ ] 反复练习至流畅自然
- [ ] 准备1分钟和3分钟两个版本

#### 模板：自我介绍结构（中文）
```
1. 基本信息（15秒）：姓名、学校、专业
2. 学术表现（30秒）：排名、绩点、核心课程
3. 科研经历（45秒）：项目、成果、你的贡献
4. 综合素质（20秒）：竞赛、实践、获奖
5. 读研规划（20秒）：研究方向 + 未来目标
```

### 阶段 2：专业问题准备（复试前2周）

#### 行动清单
- [ ] 复习核心专业课（目标院校指定教材）
- [ ] 整理常见专业面试问题（50题以上）
- [ ] 模拟面试（找同学/老师扮演考官）
- [ ] 准备「不知道」的应对策略

#### 模板：专业问题整理表
```
| 序号 | 问题 | 考察知识点 | 我的回答要点 | 参考来源 |
|------|------|------------|--------------|----------|
| 1 | 什么是XXX？ | XX理论 | 定义+举例+应用 | 教材第X章 |
```

#### 应对策略模板
```
如果遇到不会的问题：
1. 先承认："这个问题我了解得不够深入"
2. 展示思路："但我认为可以从XX角度思考..."
3. 表达学习意愿："复试后我会重点补充这方面的知识"
```

### 阶段 3：英语面试准备（复试前1周）

#### 行动清单
- [ ] 准备英文自我介绍（1分钟）
- [ ] 准备常见英语面试问答（20题）
- [ ] 练习专业英语词汇（目标方向）
- [ ] 每天口语练习30分钟

#### 模板：常见英语面试问答
```
Q1: Please introduce yourself briefly.
A: Good morning, professors. My name is XXX, from XX University...

Q2: Why do you choose our university?
A: I choose this university because...

Q3: What's your research plan?
A: My research plan is to...

Q4: Tell me about your undergraduate research experience.
A: I participated in...
```

## 输出规范

当用户提出需求时：
1. 先判断属于哪个模块（材料准备/导师联系/复试技巧）
2. 按阶段输出行动清单（用 checkbox 列表）
3. 配套输出对应模板（用代码块展示）
4. 如果用户需要完整流程，按「材料准备 → 导师联系 → 复试技巧」顺序输出全部内容

## 注意事项
- 所有模板仅供参考，需根据用户实际情况调整
- 提醒用户各院校要求不同，以目标院校官方通知为准
- 建议用户结合自身经历补充个性化内容
- 时间节点为一般参考，具体以当年保研政策为准
