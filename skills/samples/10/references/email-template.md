# 导师联系邮件模板合集

## 第一封联系邮件（标准版）

```
标题：保研推免咨询-XX大学XX专业-XXX

尊敬的XX老师：

您好！我是XX大学XX学院XX专业的XX，本科三年级学生。通过贵校官网和您的学术论文，我对您的研究方向（具体方向）产生了浓厚兴趣。现冒昧致信，恳请老师拨冗阅读。

一、个人基本情况
（学校、专业、成绩排名、英语水平）

二、科研/竞赛经历（简要）
（1-2段最突出的经历，与导师方向相关优先）

三、对老师研究方向的了解和兴趣
（读过老师哪篇论文/参加过哪个报告，为什么感兴趣）

四、期望与请求
（希望进入课题组学习，询问是否有推免名额，能否进一步交流）

五、附件说明
（已附上个人简历和成绩单）

此致
敬礼

学生：XXX
联系电话：XXX
邮箱：XXX
日期：20XX年X月X日
```

## 跟进邮件（3-5天未回复）

```
标题：保研推免咨询跟进-XX大学XX专业-XXX

尊敬的XX老师：

您好！我是XX大学XX专业的XX，上周曾致信咨询推免相关事宜，怕打扰老师工作故未电话联系。如老师方便，烦请抽空回复，期待能够得到老师的指点。

再次感谢老师拨冗阅读！

学生：XXX
日期：
```

## 导师回复后的感谢邮件

```
尊敬的XX老师：

您好！非常感谢您的回复和宝贵建议。我已认真阅读并会按照您的指导进行准备。如果有机会，希望能与您进一步深入交流。

再次感谢您的时间和指导！

学生：XXX
日期：
```

## 邮件发送小贴士

1. 发送时间：工作日上午9-11点
2. 附件命名：`简历-张三-XX大学.pdf`
3. 正文控制在500-800字，简洁明了
4. 每封邮件只联系一位导师，避免同时联系同一学院多位导师
5. 收到回复后无论结果如何，都要礼貌感谢
