# 保研全流程时间轴速查表

## 大一阶段
- [ ] 了解本校保研政策基本框架
- [ ] 保持高绩点（保研的基础）
- [ ] 咨询学长学姐，了解保研整体流程

## 大二阶段
- [ ] 深入研究本校保研细则（绩点/比赛/科研权重）
- [ ] 确认参赛身份要求（是否需队长）
- [ ] 参加1-2个高含金量比赛（数模、互联网+等）
- [ ] 积累科研经历或项目经验

## 大三上学期
- [ ] 确认自己在专业中的排名
- [ ] 初步确定目标院校范围
- [ ] 联系学长学姐获取目标院校信息

## 大三下学期
- [ ] 完善个人简历和个人陈述
- [ ] 关注目标院校夏令营通知
- [ ] 准备夏令营材料（成绩单、推荐信等）

## 暑假（夏令营季）
- [ ] 参加目标院校夏令营
- [ ] 准备自我介绍、演讲、比赛等展示内容
- [ ] 与目标导师建立联系

## 9月（预推免/九推）
- [ ] 打磨推免面试PPT
- [ ] 准备面试常见问题
- [ ] 参加推免面试

## 系统填报阶段
- [ ] 权衡offer（城市 > 专业 > 学校）
- [ ] 完成推免系统填报
- [ ] 确认最终录取结果

## 贯穿全程的心态提醒
- [ ] 保持自信：成绩好，一定有学校选你
- [ ] 焦虑是正常的，不要被焦虑支配
- [ ] 稳住心态，发挥真实水平
