# 大学保研规划指南

## 这个 Skill 解决什么

帮刚上大学有保研想法的学生，从看政策、查院校、问学长到组队干活，建立清晰的保研行动路径。

## 什么算做完

- 能说出自己学校/学院的保研硬性条件（至少3条），并对照评估自己当前差距
- 能列出至少2个目标院校的专业、招生人数、材料提交时间段
- 能从学长学姐那里获得至少2条官网文件上写不到的经验
- 能明确说出自己未来2-3年要重点做的3件事，且每件事都对应到政策要求
- 能组建一支队伍并完成至少1个比赛/项目
- 能拿出一版突出自己优势的PPT和简历

## 关键岔路口

以下每条判断都来自一次真实执行，标注了它出自哪一步。

### 在哪一步你会停下来回头验证？

- 当**看到学校保研政策文件时**时，逐条对照自己的情况，看哪些条件已满足、哪些还没满足，而不是扫一眼就过（适用：刚拿到政策文件、准备开始规划时；来源：执行第 0 步）

### 什么情况下你会要求补充信息而不是直接动手？

- 当**问学长学姐经验时**时，主动追问"官网文件上看不出来的"细节，比如哪些比赛加分多、哪些老师愿意带本科生（适用：学长学姐愿意分享时；来源：执行第 0 步）

### 哪一步必须查、必须跑，不能靠判断？

- 当**查目标院校信息时**时，必须自己去官网查，不能只依赖学长学姐转述，因为官网信息最权威、最新（适用：确定目标院校、准备申请材料时；来源：执行第 0 步）

### 什么现象一出现，你就知道当前这条路走不通？

- 当**政策要求"必须当队长"而自己觉得不适合时**时，不要纠结自己适不适合，政策怎么要求就怎么做，硬着头皮上（适用：政策硬性条件与个人意愿冲突时；来源：执行第 0 步）

## 边界与人工接管

**不适用于：**
- 已经大三/大四、马上要提交保研材料的学生，这个 Skill 的规划节奏不适合他们，他们需要的是紧急冲刺方案
- 目标不是保研（比如打算考研、出国、直接就业）的学生

**出现以下情况必须交回给人：**
- 当学生不确定自己学校的政策细节、官网信息不清晰时，必须交给学生自己去问辅导员或教务处，不能替他们做决定
