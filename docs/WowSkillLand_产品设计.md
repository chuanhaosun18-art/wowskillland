# 产品设计：迷茫期路由器（工程可开工版）

一个入口、三个流、一份地图、一个供给端。产品名 **WowSkillLand**（曾用建议名「路口」）。一句话定位：每一次「我不知道」，都有人真走过。

三条产品纪律贯穿全部界面：**不测评、不建议、不承诺。**

可浏览 HTML 版：[`迷茫期路由器_产品设计.html`](./迷茫期路由器_产品设计.html)。

---

## 供给的三层结构：我们做的是「能行动的经验贴」

好的经验贴从不靠给答案解决迷茫——它让人在别人的故事里认出自己，顿悟发生在读者脑子里。因此供给分三层，缺一不可：

1. **故事层**：学长口述全文，共鸣的载体，挂在卡背后可下钻。
2. **卡片层**：抽出的可执行第一步，补经验贴「读完不知道明天干嘛」的缺陷。
3. **分布层**：分叉数据与失败恢复卡，补单篇经验贴样本=1 和幸存者偏差。

匹配的不是「最佳答案」，而是「处境和你最像的人的完整经历」。推荐理由直接写在界面上：*TA 当年也是二本转码、也是大二下才开始慌的。*

## 六个界面（按用户旅程）

### S1 · 入口对话（路由器）

- 只有一个输入框：「说说你现在的不知道」。一句话进来，判定迷茫形态：探索型 / 抉择型 / 行动型 / 情绪类（拦截，给校内心理支持入口，不落任何记录）。
- 判定结果必须明示。路由透明本身是信任的一部分，也是兜底：判错了用户可以一键改道。

### S2 · 探索流：访谈 → 假设 → 选卡

- 轻访谈 ≤5 轮、每轮 1–2 问，只采处境与行为信号，不做任何人格测评。
- 产出方向假设，每张必须引用访谈原话作为依据；下挂匹配的第一步卡。
- 第一步卡展示：两周剧本、完成标准、学长判断点、不适合谁、同处境验证数、去向分布、`choose_if` 一句话。
- 每张卡可下钻「TA 的完整故事」。

### S3 · 微尝试进行中（Skill 的运行时）

- 选卡即装载：剧本、判断点、边界、学长原材料挂进陪跑 Agent。
- 四种调用时刻：参数化展开、执行中求助、判断点定时触发、边界停机。
- 结束只问两问 + 一句 verdict。放弃不是失败。
- 帖子只能被读，Skill 被执行——并且知道自己什么时候失效。

### S4 · 探索地图（个人页）

- 时间轴叙事：什么时候带着什么迷茫来过、试了什么、感受原话、下一步试什么。
- 禁止评价性词汇（优秀 / 擅长 / 适合）。无分数、无雷达图、无标签。

### S5 · 路口页（抉择型出口）

- 走过这个路口的总人数、各去向的绝对人数、改道最常发生的节点、每一支的代价原话。
- 顶部固定：「我们不替你选，只让你看见走过的人。」全页无建议、无倾向排序、无百分比。

### S6 · 学长录入端（供给闭环）

- 10 分钟访谈式录入：AI 问、学长说，自动抽取四槽；学长只确认不撰写。
- 每个字段必须对应口述原文，对不上的丢弃。「不适合谁」留空则不能发布。
- 口述全文脱敏后保留为故事层。

**编排态**：行动型迷茫（「我决定考研了怎么排」）识别后，只用别人真走过的 Path 排节点；没人走过则拒绝生成，不凭空编时间表。

## Skill 运行时与被动供给

### Skill 包格式

- **instructions**：学长经验转成的行为约束，注入陪跑 Agent。
- **resources**：原信、模板、清单、周安排。
- **triggers & boundary**：时间触发、语义触发、停机条件。

运行时：一个基础陪跑 Agent + 动态挂载的 Skill 包。两种形态：陪跑态（持续两周）与即时态（一次产物）。

### 被动供给三级阶梯（用户只确认，不撰写）

| 层级 | 触发 | 用户动作 | 产出 |
|---|---|---|---|
| 验证级 | 每次尝试结束 | 两问 + verdict | 卡片验证数与边界数据 |
| 变体级 | 实际走法偏离原剧本 | 对变体草稿点一次确认 | 变体卡入池，署名归用户 |
| 新卡级 | 走通许愿池无人区 | 确认蒸馏出的新卡 + 故事层 | 他成为下一届的「学长」 |

冷启动卡用完之后，供给来自使用本身的副产品，不靠邀请学长做慈善。

## 数据模型（8 张表）

| 表 | 关键字段 | 说明 |
|---|---|---|
| users | grade, major, weekly_hours | 处境字段，匹配用 |
| moments | raw_text, routed_state | 每一次「我不知道」 |
| interviews | moment_id, context, turns | 访谈快照 |
| hypotheses | label, evidence_quote | 依据必须是访谈原话 |
| cards | trigger / script / boundary / source_transcript | 第一步卡 = Skill 包 |
| attempts | verdict, flow_moments, escape_moments | 放弃也是合法终态 |
| forks | walked_count, branches | 只存绝对人数与代价原话 |
| wishes | direction_label | 无卡时的许愿池 |

## AI 能力（6 个任务，每个带硬约束）

| 任务 | 做什么 | 硬约束 |
|---|---|---|
| A1 路由器 | 一句话分类四态 | 情绪类立即拦截；判定必须明示 |
| A2 迷茫访谈 | ≤5 轮采处境与行为 | 只问经历，不问「你是什么样的人」 |
| A3 假设生成 | 方向假设 | 必须附访谈原话；措辞是「值得一试」不是「你适合」 |
| A4 卡片匹配 | 规则过滤 + choose_if | 过滤是规则不是 AI；无卡时如实说还没有 |
| A5 学长抽取 | 口述 → 四槽 | 对不上即丢弃；学长只确认不撰写 |
| A6 地图叙事 | attempts → 叙事 | 禁评价性形容词 |

## 场景 × Skill 化判定

总原则：Skill 只承载「下一步动作」，不承载情绪修复和人生答案。每个场景拆成：可行动内核进卡、认知校准给分布、不可控显式标注、纯情绪拦截。

| 场景 | 能进卡 | 给分布 | 不可控 / 情绪 |
|---|---|---|---|
| 大一 · 方向迷茫 | 方向微尝试第一步卡 | 同处境去向分布 | 兴趣何时出现不可控 |
| 大一 · 社交 | 破冰 / 聚餐 / 社团面试动作卡 | 「多久才有稳定朋友圈」 | 对方是否回应不可控 |
| 大一 · 孤独感 | **不做卡** | 同期有同感的数据 | 持续 → 校心理入口 |
| 大一 · 时间掌控 | 同专业一周模板、ddl 急救 | 学长真实有效学习时长 | — |
| 大二 · peer pressure | 调整信息环境的具体做法 | 学长暑假真实去向 | 他人节奏不可控 |
| 大二 · 专业迷茫 | 旁听课、约转过专业的学长 | 转专业分叉与代价 | 名额不可控 |
| 大三 · 前途分水岭 | 决定后的编排 | 保研/考研/就业/出国路口 | 名额与 offer 不可控 |
| 大三 · 失败处理 | 失败恢复卡 | 「失败之后的人后来怎样了」 | 冲击期先陪伴不推卡 |

「时期 × 场景」矩阵是内容生产的组织方式，不是产品导航。用户入口仍然只有一个输入框。

## 三个关键取舍

1. **两周时间盒无法现场发生** → Demo 用双视角：评委走第 0 天，再切到预置的第 14 天账号。
2. **路由可能判错** → 不赌准确率，赌改道成本为零。
3. **分叉样本量小** → 只给绝对人数不给百分比，小样本诚实呈现。
